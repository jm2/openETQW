# OpenETQW Compatibility Ledger

> This ledger records deliberate deviations from original (SDK or retail) ETQW 1.5 behavior, serialization semantics, and data handling (CHARTER §7.4).
> Since owner decision D7 (2026-09-22), OpenETQW makes a **clean network break** from retail 1.5, as openQ4 did: it speaks its own versioned protocol, and retail peers cannot connect. Rows written before D7 describe "interop risk" and are kept for history; read that column as gameplay or fidelity risk.

## Network directions (after D7)
1. **OpenETQW client ↔ OpenETQW server (dedicated/listen)**: supported (M3)
2. **OpenETQW clients on different OSes ↔ OpenETQW server**: supported goal (M3)
3. **Retail 1.5 client or server ↔ OpenETQW**: not supported by design (D7); refused at connect
