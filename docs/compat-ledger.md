# OpenETQW Compatibility Ledger

> This ledger records every known behavioral, serialization, and wire protocol divergence risk between OpenETQW and retail ETQW 1.5 per CHARTER §7.4.
> Each row tracks: Behavior · What SDK Establishes · What is Unknown about Retail · Current OpenETQW Behavior · Evidence · Interop Risk · Migration Strategy.

## Interoperability Direction Status
1. **Direction 1: OpenETQW client ↔ OpenETQW server (dedicated/listen)**: Planned (M3)
2. **Direction 2: OpenETQW client → retail 1.5 server**: Planned (M6)
3. **Direction 3: Retail 1.5 client → OpenETQW server**: Planned (M6)
4. **Direction 4: Mixed retail and OpenETQW clients → OpenETQW server**: Planned (M6)
